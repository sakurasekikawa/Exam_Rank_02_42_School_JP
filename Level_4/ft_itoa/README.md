## 課題

```BASH
演習名 : ft_itoa
提出ファイル : ft_itoa.c
使用可能な関数 : malloc
--------------------------------------------------------------------------------

`int` を1つ受け取り、それをヌル終端文字列に変換する関数を書いてください。関数は
結果を、あなたが確保した `char` の配列で返します。

関数は次のように宣言してください：

char	*ft_itoa(int nbr);
```

**オフラインでのコンパイルとテスト**

- **コンパイル:** `gcc -Wall -Wextra -Werror ft_itoa.c -o ft_itoa`（テストファイルが提供されている場合は、そのテストと一緒にコンパイルしてください）
- **例:** `ft_itoa` を呼び出す `test.c` を作成: `gcc ft_itoa.c test.c -o test && ./test`

補足: コマンドはリポジトリのルートから実行してください。
