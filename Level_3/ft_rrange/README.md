## 課題

```BASH
演習名 : ft_rrange
提出ファイル : ft_rrange.c
使用可能な関数 : malloc
--------------------------------------------------------------------------------

次の関数を書いてください：

int     *ft_rrange(int start, int end);

この関数は（malloc() を使って）整数の配列を確保し、end から start まで（start と
end を含む）連続した値を降順に入れ、その配列の最初の要素へのポインタを返してくだ
さい。

例：

- (1, 3) の場合、3, 2, 1 を含む配列を返します
- (-1, 2) の場合、2, 1, 0, -1 を含む配列を返します
- (0, 0) の場合、0 を含む配列を返します
- (0, -3) の場合、-3, -2, -1, 0 を含む配列を返します
```

**オフラインでのコンパイルとテスト**

- **コンパイル:** `gcc -Wall -Wextra -Werror ft_rrange.c -o ft_rrange`（テストファイルが提供されている場合は、そのテストと一緒にコンパイルしてください）
- **例:** `ft_rrange` を呼び出す小さな `test.c` を作成してコンパイル: `gcc ft_rrange.c test.c -o test && ./test`

補足: コマンドはリポジトリのルートから実行してください。
