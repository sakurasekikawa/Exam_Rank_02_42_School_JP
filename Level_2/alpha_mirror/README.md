## 課題

```BASH
演習名 : alpha_mirror
提出ファイル : alpha_mirror.c
使用可能な関数 : write
--------------------------------------------------------------------------------

alpha_mirror という名前のプログラムを書いてください。このプログラムは文字列を1つ
受け取り、アルファベットの各文字を対になる文字（鏡文字）に置き換えて表示し、最後に
改行を1つ出力します。

'a' は 'z' に、'Z' は 'A' に、
'd' は 'w' に、'M' は 'N' に、
というように変換します。

大文字・小文字は変更しません。

引数の数が1個でない場合は、改行のみを表示してください。

例:

$>./alpha_mirror "abc"
zyx
$>./alpha_mirror "My horse is Amazing." | cat -e
Nb slihv rh Znzarmt.$
$>./alpha_mirror | cat -e
$
$>
```
