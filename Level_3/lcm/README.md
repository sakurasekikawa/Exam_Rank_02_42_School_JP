## 課題

```BASH
演習名 : lcm
提出ファイル : lcm.c
使用可能な関数 : 
--------------------------------------------------------------------------------

2つの `unsigned int` を引数として受け取り、その最小公倍数（LCM）を計算して返す
関数を書いてください。

2つの非ゼロの整数の最小公倍数とは、その両方で割り切れる最小の正の整数のことです。

最小公倍数は次の2つの方法で計算できます：

- それぞれの整数の倍数を計算し、0以外の共通の倍数が見つかるまで続ける。

- 2つの整数の最大公約数（GCD）を使って次のように計算する：

  LCM(x, y) = | x * y | / GCD(x, y)

  | x * y | は「x と y の積の絶対値」を意味します。

少なくとも一方の整数が0の場合、最小公倍数は0とします。

関数は次のようにプロトタイプ宣言してください：

  unsigned int    lcm(unsigned int a, unsigned int b);
```
