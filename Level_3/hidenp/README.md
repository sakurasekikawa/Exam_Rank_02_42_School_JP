## 課題

```BASH
演習名 : hidenp
提出ファイル : hidenp.c
使用可能な関数 : write
--------------------------------------------------------------------------------

hidenp という名前のプログラムを書いてください。このプログラムは2つの文字列を
受け取り、1番目の文字列が2番目の文字列に「隠れている」場合は 1 と改行を表示し、
そうでない場合は 0 と改行を表示します。

s1 と s2 を文字列とします。s1 が s2 に隠れているとは、s1 の各文字を、s1 内での
出現順序を保ったまま s2 の中に見つけられることを意味します。また、空文字列はどんな
文字列にも隠れているとみなします。

引数の数が2個でない場合は、プログラムは改行を表示します。

例:

$>./hidenp "fgex.;" "tyf34gdgf;'ektufjhgdgex.;.;rtjynur6" | cat -e
1$
$>./hidenp "abc" "2altrb53c.sse" | cat -e
1$
$>./hidenp "abc" "btarc" | cat -e
0$
$>./hidenp | cat -e
$
$>
```
