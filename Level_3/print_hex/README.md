## 課題

```BASH
演習名 : print_hex
提出ファイル : print_hex.c
使用可能な関数 : write
--------------------------------------------------------------------------------

10進数で表された0以上の数値を1つ受け取り、それを16進数（小文字）で表示し、最後に
改行を1つ出力するプログラムを書いてください。

引数の数が1個でない場合は、プログラムは改行を表示します。

例:

$> ./print_hex "10" | cat -e
a$
$> ./print_hex "255" | cat -e
ff$
$> ./print_hex "5156454" | cat -e
4eae66$
$> ./print_hex | cat -e
$
```
