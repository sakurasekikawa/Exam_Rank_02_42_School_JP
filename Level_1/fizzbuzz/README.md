## 課題

```BASH
演習名 : fizzbuzz
提出ファイル : fizzbuzz.c
使用可能な関数 : write
--------------------------------------------------------------------------------

1から100までの数字を、それぞれ改行で区切って表示するプログラムを書いてください。

その数が3の倍数の場合は、代わりに 'fizz' を表示します。

その数が5の倍数の場合は、代わりに 'buzz' を表示します。

その数が3の倍数かつ5の倍数の場合は、代わりに 'fizzbuzz' を表示します。

例:

$>./fizzbuzz
1
2
fizz
4
buzz
fizz
7
8
fizz
buzz
11
fizz
13
14
fizzbuzz
[...]
97
98
fizz
buzz
$>
```
