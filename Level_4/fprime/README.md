## 課題

```BASH
演習名 : fprime
提出ファイル : fprime.c
使用可能な関数 : printf, atoi
--------------------------------------------------------------------------------

正の整数を1つ受け取り、その素因数を標準出力に表示し、最後に改行を1つ出力する
プログラムを書いてください。

素因数は昇順に、`*` で区切って表示し、表示された式がそのまま計算結果になるように
してください。

引数の数が1個でない場合は、単に改行を表示してください。

入力が与えられる場合、それは常に有効な値です。

例:

$> ./fprime 225225 | cat -e
3*3*5*5*7*11*13$
$> ./fprime 8333325 | cat -e
3*3*5*5*7*11*13*37$
$> ./fprime 9539 | cat -e
9539$
$> ./fprime 804577 | cat -e
804577$
$> ./fprime 42 | cat -e
2*3*7$
$> ./fprime 1 | cat -e
1$
$> ./fprime | cat -e
$
$> ./fprime 42 21 | cat -e
$
```

**オフラインでのコンパイルとテスト**

- **コンパイル:** `gcc -Wall -Wextra -Werror fprime.c -o fprime`
- **例:** `./fprime 225225 | cat -e`

補足: コマンドはリポジトリのルートから実行してください。
