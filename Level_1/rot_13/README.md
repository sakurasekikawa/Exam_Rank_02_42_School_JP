## 課題

```BASH
演習名 : rot_13
提出ファイル : rot_13.c
使用可能な関数 : write
--------------------------------------------------------------------------------

文字列を1つ受け取り、各文字をアルファベット順で13文字先の文字に置き換えて表示する
プログラムを書いてください。

'z' は 'm' に、'Z' は 'M' になります。大文字・小文字は変更しません。

出力の最後には改行を1つ出力します。

引数の数が1個でない場合は、プログラムは改行を表示します。

例:

$>./rot_13 "abc"
nop
$>./rot_13 "My horse is Amazing." | cat -e
Zl ubefr vf Nznmvat.$
$>./rot_13 "AkjhZ zLKIJz , 23y " | cat -e
NxwuM mYXVWm , 23l $
$>./rot_13 | cat -e
$
$>
$>./rot_13 "" | cat -e
$
$>
```
