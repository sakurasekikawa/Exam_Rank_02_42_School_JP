## 課題

```BASH
演習名 : paramsum
提出ファイル : paramsum.c
使用可能な関数 : write
--------------------------------------------------------------------------------

プログラムに渡された引数の数を表示し、最後に改行を1つ出力するプログラムを書いて
ください。

引数がない場合は、単に 0 と改行を表示してください。

例:

$>./paramsum 1 2 3 5 7 24
6
$>./paramsum 6 12 24 | cat -e
3$
$>./paramsum | cat -e
0$
$>
```
