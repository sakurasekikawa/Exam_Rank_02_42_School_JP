## 課題

```BASH
演習名 : add_prime_sum
提出ファイル : add_prime_sum.c
使用可能な関数 : write, exit
--------------------------------------------------------------------------------

正の整数を1つ引数として受け取り、その整数以下のすべての素数の合計を表示し、最後に
改行を1つ出力するプログラムを書いてください。

引数の数が1個でない場合、または引数が正の数でない場合は、単に `0` と改行を表示して
ください。

例:

$>./add_prime_sum 5
10
$>./add_prime_sum 7 | cat -e
17$
$>./add_prime_sum | cat -e
0$
$>
```

**オフラインでのコンパイルとテスト**

- **コンパイル:** `gcc -Wall -Wextra -Werror add_prime_sum.c -o add_prime_sum`
- **例:** `./add_prime_sum 7 | cat -e`

補足: コマンドはリポジトリのルートから実行してください。
