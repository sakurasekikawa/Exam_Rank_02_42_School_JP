## 課題

```BASH
演習名 : ft_list_size
提出ファイル : ft_list_size.c, ft_list.h
使用可能な関数 : 
--------------------------------------------------------------------------------

渡された連結リストの要素数を返す関数を書いてください。

関数は次のように宣言してください：

int	ft_list_size(t_list *begin_list);

次の構造体を使用し、ft_list.h という名前のファイルとして提出してください：

typedef struct    s_list
{
    struct s_list *next;
    void          *data;
}                 t_list;
```
