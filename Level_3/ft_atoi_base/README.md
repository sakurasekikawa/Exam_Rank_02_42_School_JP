## 課題

```BASH
演習名 : ft_atoi_base
提出ファイル : ft_atoi_base.c
使用可能な関数 : なし
--------------------------------------------------------------------------------

文字列引数 str（N進数、N <= 16）を10進数の整数に変換して返す関数を書いてください。

入力として認識される文字は次の通りです：0123456789abcdef

これらはもちろん、指定された基数に応じて絞り込まれます。例えば、4進数の場合は
"0123" を認識し、16進数の場合は "0123456789abcdef" を認識します。

大文字も認識する必要があります："12fdb3" は "12FDB3" と同じものとして扱われます。

マイナス記号（'-'）は、文字列の最初の文字である場合にのみ解釈されます。

関数は次のように宣言してください：

int	ft_atoi_base(const char *str, int str_base);
```
