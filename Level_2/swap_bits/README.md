## 課題

```BASH
演習名 : swap_bits
提出ファイル : swap_bits.c
使用可能な関数 : 
--------------------------------------------------------------------------------

1バイトを受け取り、その上位4ビットと下位4ビットを入れ替えて（例のように）結果を
返す関数を書いてください。

関数は次のように宣言してください：

unsigned char	swap_bits(unsigned char octet);

例:

  1 byte
_____________
 0100 | 0001
     \ /
     / \
 0001 | 0100
```
