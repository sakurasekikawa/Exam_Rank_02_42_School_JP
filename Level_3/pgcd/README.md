## 課題

```BASH
演習名 : pgcd
提出ファイル : pgcd.c
使用可能な関数 : printf, atoi, malloc, free
--------------------------------------------------------------------------------

int型に収まる2つの正の整数を表す文字列を2つ受け取るプログラムを書いてください。

それらの最大公約数を表示し、最後に改行を1つ出力してください（最大公約数は常に正の
整数です）。

引数の数が2個でない場合は、改行を表示してください。

例:

$> ./pgcd 42 10 | cat -e
2$
$> ./pgcd 42 12 | cat -e
6$
$> ./pgcd 14 77 | cat -e
7$
$> ./pgcd 17 3 | cat -e
1$
$> ./pgcd | cat -e
$
```
