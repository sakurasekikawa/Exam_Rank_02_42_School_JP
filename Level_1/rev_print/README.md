## 課題

```BASH
演習名 : rev_print
提出ファイル : rev_print.c
使用可能な関数 : write
--------------------------------------------------------------------------------

文字列を1つ受け取り、その文字列を逆順に表示し、最後に改行を1つ出力するプログラムを
書いてください。

引数の数が1個でない場合は、プログラムは改行を表示します。

例:

$> ./rev_print "zaz" | cat -e
zaz$
$> ./rev_print "dub0 a POIL" | cat -e
LIOP a 0bud$
$> ./rev_print | cat -e
$
```
