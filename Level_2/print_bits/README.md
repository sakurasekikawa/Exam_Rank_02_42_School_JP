## 課題

```BASH
演習名 : print_bits
提出ファイル : print_bits.c
使用可能な関数 : write
--------------------------------------------------------------------------------

1バイトを受け取り、それを2進数で表示する関数を書いてください（最後に改行は付けま
せん）。

関数は次のように宣言してください：

void	print_bits(unsigned char octet);

例えば、print_bits に 2 を渡すと "00000010" が表示されます。
```
