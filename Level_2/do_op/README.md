## 課題

```BASH
演習名 : do_op
提出ファイル : *.c, *.h
使用可能な関数 : atoi, printf, write
--------------------------------------------------------------------------------

3つの文字列を受け取るプログラムを書いてください：
- 1番目と3番目の文字列は、int型に収まる10進数の符号付き整数を表しています。
- 2番目の文字列は、+ - * / % のいずれかの算術演算子です。

プログラムは要求された算術演算の結果を表示し、最後に改行を1つ出力してください。
引数の数が3個でない場合は、プログラムは改行のみを表示してください。

文字列に誤植や余分な文字は含まれないものとします。入力・出力に含まれる負の数には、
先頭に '-' が1つだけ付きます。演算結果はint型に収まります。

例:

$> ./do_op "123" "*" 456 | cat -e
56088$
$> ./do_op "9828" "/" 234 | cat -e
42$
$> ./do_op "1" "+" "-43" | cat -e
-42$
$> ./do_op | cat -e
$
```
