## 課題

```BASH
演習名 : ft_range
提出ファイル : ft_range.c
使用可能な関数 : malloc
--------------------------------------------------------------------------------

次の関数を書いてください：

int     *ft_range(int start, int end);

この関数は（malloc() を使って）整数の配列を確保し、start から end まで（start と
end を含む）連続した値を入れ、その配列の最初の要素へのポインタを返してください。

例：

- (1, 3) の場合、1, 2, 3 を含む配列を返します。
- (-1, 2) の場合、-1, 0, 1, 2 を含む配列を返します。
- (0, 0) の場合、0 を含む配列を返します。
- (0, -3) の場合、0, -1, -2, -3 を含む配列を返します。
```
