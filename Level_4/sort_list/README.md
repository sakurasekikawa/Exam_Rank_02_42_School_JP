## 課題

```BASH
演習名 : sort_list
提出ファイル : sort_list.c
使用可能な関数 : 
--------------------------------------------------------------------------------

次の関数を書いてください：

t_list	*sort_list(t_list* lst, int (*cmp)(int, int));

この関数は、関数ポインタ `cmp` を使って順序を決定しながら、引数として渡された
リストをソートし、ソート後のリストの最初の要素へのポインタを返してください。

重複した値はそのまま保持してください。

入力は常に整合性のあるものとします。

提供されている `list.h` ファイルに記述された `t_list` 型を使用してください。この
ファイルは `#include "list.h"` としてインクルードする必要がありますが、提出はしな
いでください。あなたのコードのコンパイルには、私たちが用意した独自のバージョンを
使用します。

`cmp` に渡される関数は、`a` と `b` が正しい順序であれば常に0以外の値を返し、そう
でなければ `0` を返します。

例えば、次の関数を `cmp` として使用すると、リストは昇順にソートされます：

int ascending(int a, int b)
{
	return (a <= b);
}
```

**オフラインでのコンパイルとテスト**

- **コンパイル:** `gcc -Wall -Wextra -Werror sort_list.c -o sort_list`（テストファイルが提供されている場合は、そのテストと一緒にコンパイルしてください）
- **例:** `list.h` をインクルードし `sort_list` を呼び出す `test.c` を作成: `gcc sort_list.c test.c -o test && ./test`

補足: コマンドはリポジトリのルートから実行してください。
