## 課題

```BASH
演習名 : reverse_bits
提出ファイル : reverse_bits.c
使用可能な関数 : 
--------------------------------------------------------------------------------

1バイトを受け取り、それをビットごとに反転させて（例のように）結果を返す関数を
書いてください。

関数は次のように宣言してください：

unsigned char	reverse_bits(unsigned char octet);

例:

  1 byte
_____________
 0010  0110
	 ||
	 \/
 0110  0100
```
