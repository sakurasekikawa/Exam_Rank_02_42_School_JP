## 課題

```BASH
演習名 : ft_split
提出ファイル : ft_split.c
使用可能な関数 : malloc
--------------------------------------------------------------------------------

文字列を1つ受け取り、それを単語ごとに分割して、`NULL` で終端された文字列の配列と
して返す関数を書いてください。

「単語」とは、スペース・タブ・改行、または文字列の先頭・末尾で区切られた文字列の
一部分のことです。

関数は次のように宣言してください：

char    **ft_split(char *str);
```

**オフラインでのコンパイルとテスト**

- **コンパイル:** `gcc -Wall -Wextra -Werror ft_split.c -o ft_split`（テストファイルが提供されている場合は、そのテストと一緒にコンパイルしてください）
- **例:** `ft_split` を呼び出す `test.c` を作成: `gcc ft_split.c test.c -o test && ./test`

補足: コマンドはリポジトリのルートから実行してください。
